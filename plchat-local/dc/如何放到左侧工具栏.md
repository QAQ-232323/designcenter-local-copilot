# 把 Copilot 放到最左侧竖排工具栏

## 方案一:用我做的工具栏文件(推荐)

文件已放好:

    E:\AIprojects\nx-skill\nx_runtime\startup\nx_copilot.tbr

它定义了三条命令:

| 按钮 | 引用的命令 |
|---|---|
| Copilot | `UG_APP_COPILOT`(Designcenter 内置 AI 面板) |
| Review Plan | `NX_SKILL_CONTROL_REVIEW_PLAN` |
| Start NX Skill Live Bridge | `NX_SKILL_CONTROL_START_BRIDGE` |

**前提**:下面这个环境变量必须设(NX 才会去找这个目录):

    setx UGII_USER_DIR "E:\AIprojects\nx-skill\nx_runtime"

**启用步骤**:

1. 双击 `plchat-local\dc\user-dir-on.cmd`(或手工 setx)
2. **重启 Designcenter**
3. 在功能区空白处右键 → **定制**(或菜单 工具 → 定制)
4. 切到 **工具栏** 页签,列表里找到 **Copilot** → 勾选
5. 如果它没有自动靠在最左边:按住标题条**拖到窗口最左边缘**,松手即可停靠成竖排
6. 关闭定制对话框

之后左侧就会常驻一个 Copilot 图标(和 Review Plan / Live Bridge),点一下就开。

## 方案二:不用文件,手工拖(立即能做)

1. 功能区空白处右键 → **定制**
2. 在 **命令** 页签里,分类选 **帮助**(或直接搜索框输 `Copilot`)
3. 把 **Copilot** 图标**拖到窗口最左侧边缘**,出现竖直停靠条时松手
4. 关闭定制对话框

这会写进你的角色/用户界面设置,重启后仍在。

## 关于左侧那条竖条本身

你截图里那条是 NX 的 **Resource Bar(资源条)**,里面是导航器/面板类页签
(部件导航器、装配导航器、Web 浏览器、工具箱…)。**它装的是"面板",不是普通命令** ——
所以 Copilot 这类命令的合适位置是**左侧停靠的自定义工具栏**,也就是上面两个方案做出来的效果:
视觉上同样贴在最左侧,但是竖排按钮条。

## 想连我们的本地宿主一起用

上面只解决"入口在哪"。要让点开的 Copilot 面板加载**我们的页面 + 我们的模型**,
还需要(见 `plchat-local\dc\`):

    copilot-hooks-on.cmd      :: 把面板的网页和后端都换成我们本地的
    review-workspace-on.cmd   :: 让 NX 与宿主共用复核队列(否则 Review Plan 找不到计划)
